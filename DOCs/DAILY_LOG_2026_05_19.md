  - Refined the greeting guard so that greeting filtering only applies to the *first* user message in a chat history. Subsequent greetings or casual inputs within an ongoing conversation context are passed to the agent naturally.

### 2. React Native Frontend (salesopsapp)
- **Google Sign-In Native Setup & Configuration**:
  - Configured `@react-native-google-signin/google-signin` on iOS (with `GoogleService-Info.plist` and CocoaPods settings) and Android.
  - Updated `AccountScreen.tsx` to dynamically query Google Client IDs and scopes from `/calendar/config` on the backend, falling back to local environment configs if the API call fails.
- **Custom ToggleSwitch Component (`components/ToggleSwitch.tsx`)**:
  - Built a custom animated toggle switch replacement for React Native's default `<Switch>` to keep visual aesthetics premium and consistent across dark mode settings.
- **Pagination & Infinite Scroll on Discovery Screen (`screens/DiscoveryScreen.tsx`)**:
  - Replaced bulk-loading with proper page offset controls (pages of size 10).
  - Wired `onEndReached` callback with a loading indicator footer for seamless infinite scrolling.
- **Runs Tracking & Interactive Logs (`screens/LogsScreen.tsx` & `components/RunLogCard.tsx`)**:
  - Created a new `Logs` hub in settings allowing users to inspect past autonomous execution runs fetched dynamically from the database (`/runs/` endpoint via `runsApi.ts`).
  - Added pull-to-refresh, skeleton-load states, and page offset controls for log entries.
- **Chat Screen Markdown Render & Layout Polish (`screens/ChatScreen.tsx`)**:
  - Integrated `react-native-markdown-display` to format AI outputs dynamically (bold, italic, lists, inline code, blocks, and blockquotes).
  - Redesigned `KeyboardAvoidingView` behavior around flatlists and chat composer components to ensure correct offset and viewport calculations across iOS & Android when the keyboard appears.
